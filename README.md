# MetaboAnálise

Pré-processamento e estatística de metabolômica no estilo MetaboAnalyst, direto no navegador
(PCA, HCA, heatmap, PLS-DA, volcano, Venn/UpSet e anotação GNPS2), em português e inglês.

**Acesse:** https://giovannibonatti.github.io/metaboanalise-app/

- Não precisa instalar nada: o Python roda no próprio navegador (Pyodide). A primeira abertura leva cerca de 30 s.
- Seus dados não saem do seu computador: o arquivo CSV é processado localmente.
- Passe o mouse sobre o ícone (i) de cada opção para ver o que ela faz.

Este repositório contém apenas a página gerada (`index.html`).
